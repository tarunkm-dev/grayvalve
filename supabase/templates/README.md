# Auth email templates

Generated by `scripts/email-templates.mjs` (`npm run emails`). Don't edit these files by hand.

Paste each file into **Supabase → Authentication → Emails → Templates**, with the subject shown:

| Supabase template | File | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Confirm your Grayvalve email |
| Invite user | `invite.html` | You're invited to Grayvalve |
| Magic link | `magic-link.html` | Your Grayvalve sign-in link |
| Change email address | `change-email.html` | Confirm your new Grayvalve email |
| Reset password | `reset-password.html` | Reset your Grayvalve password |
| Reauthentication | `reauthentication.html` | Your Grayvalve security code |

Links use `{{ .SiteURL }}`, which comes from **Authentication → URL Configuration → Site URL**, so
that must be the live site (for now `https://grayvalve.vercel.app`).
